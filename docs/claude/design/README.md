# ต้นแบบ UI แบบ glass ของ Luma Camera

ไฟล์ในโฟลเดอร์นี้คือต้นแบบที่ใช้ตกลงหน้าตาและการเคลื่อนไหวของแอป ก่อนเขียนเป็นโค้ด Kotlin บน branch `claude/glass-ui`
ถ้าโค้ดในแอปกับต้นแบบไม่ตรงกัน ให้ถือต้นแบบเป็นตัวกำหนดหน้าตา และถือ `docs/claude/UI_MOTION_PROPOSAL.md` (branch `claude/ui-motion-proposal`) เป็นตัวกำหนดค่าตัวเลข

## ไฟล์

| ไฟล์ | เนื้อหา |
|---|---|
| `Main.dc.html` | หน้ากล้องทั้งหมด: แถบสถานะ, แถบโหมดและตัวแก้, แผงตัวเลือกที่ปัดขึ้น, ปรับแต่งภาพ, โปร, ซูมและวงล้อ, แถบแสงและโฟกัส, กลางคืน, มาโคร, วิดีโอและวิดีโอโปร |
| `Settings.dc.html` | หน้าตั้งค่าเต็มจอ, ค้นหา, เมนูเลือกแบบ glass, สวิตช์ |
| `Gallery.dc.html` | แกลเลอรี Luma กับทั้งเครื่อง, หมวด, ค้นหา, กดค้างดูตัวอย่าง |
| `canvas.json` | ลำดับและขนาดของหน้าจอในต้นแบบ |
| `gen_kf.py` | สคริปต์สร้าง keyframes ของ spring (ฟองที่ขยายเป็นแผง) ผลลัพธ์ฝังอยู่ใน `Main.dc.html` แล้ว |

## วิธีอ่าน

ไฟล์ `.dc.html` เป็น HTML ธรรมดาที่มี CSS และ JavaScript อยู่ในไฟล์เดียว อ่านเป็นซอร์สโค้ดได้ทันที
แต่เปิดในเบราว์เซอร์ตรง ๆ จะไม่แสดงผล เพราะต้องใช้ตัวรันของ Claude Design (`support.js`) ซึ่งไม่ได้อยู่ใน repo

จุดที่ควรดูใน `Main.dc.html`:
- ค่าคงที่ช่วงบนของสคริปต์ (`MODES`, ไอคอน SVG path) ตรงกับ `Icons` ใน `GlassKit.kt`
- ฟังก์ชัน `liquid()` คือการขยายแบบชิ้นเดียว ตรงกับ `Liquid.show/hide`
- ฟังก์ชันของแถบเลื่อนกลาง (ลากตามนิ้ว, เด้งปลาย, ดีด, snap) ตรงกับ `CenterStrip`
- คลาส CSS `.glass` และตัวแปรสี ตรงกับ `Glass` และ `GlassDrawable`

## สิ่งที่ตั้งใจไว้แต่ยังไม่ได้ทำในแอปจริง

- สไตล์ภาพ ความสว่าง ความอุ่น ยังใช้กับภาพพรีวิวอย่างเดียว ยังไม่ลงไฟล์
- ชีตย่อยบางอัน (ซูม A→B, ตั้งค่าเฟรม AI) ยังใช้ปุ่มแบบเก่าบนพื้น glass
- รายละเอียดอื่นดูได้ที่ `docs/claude/GLASS_UI_IMPLEMENTATION.md`
