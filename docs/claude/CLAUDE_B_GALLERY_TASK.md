## ปัญหาจากผู้ใช้ (ทดสอบบนเครื่องจริง)

1. หน้าแกลเลอรียังไม่ตามดีไซน์
2. บางภาพหายไปเลย: ดูใน `showGrid` adapter ตอนนี้ภาพที่ถอดรหัสไม่ได้ทิ้ง cell ไว้ด้วย alpha 0 ควรแสดง placeholder และลองวิธีอื่นก่อนยอมแพ้ เช่น `loadThumbnail`, `PhotoMedia.thumbnail` และ thumbnail ของวิดีโอ ต้องตรวจ cell ที่ถูก recycle ด้วย
3. แถบเมนูบนมองไม่เห็นหรือหาไม่เจอ: ตรวจ contrast ของปุ่ม glass บนพื้นดำ และ inset ด้านบน
4. ในแท็บทั้งเครื่องหาอัลบั้มไม่เจอ: ต้นแบบมีแถว "อัลบั้มในเครื่อง" เป็นการ์ดปกพร้อมชื่อและจำนวน แตะแล้วกรองตามอัลบั้มนั้น
5. เปิดแกลเลอรีแล้วเห็นแค่ภาพล่าสุด อยากมีปุ่มไปหน้ารูปทั้งหมดจากหน้าดูภาพ ส่วนปุ่มย้อนกลับในหน้าดูภาพควรกลับไปหน้ารวม ไม่ใช่ปิดแกลเลอรี

## สิ่งที่ต้นแบบมีและควรทำให้ครบ

- หัวหน้าจอ "แกลเลอรี" มีปุ่มกลับไปกล้องและปุ่มค้นหาที่ขยายเป็นช่องค้นหา
- แท็บแหล่งรูป (Luma และทั้งเครื่อง) มี highlight แบบ glass เลื่อนตาม
- แถวอัลบั้มในเครื่อง, แถบหมวดที่ตัวที่เลือกอยู่กลาง (ใช้ `CenterStrip` ได้), grid, ปุ่มเลือกหลายภาพ
- เมื่ออนุญาตบางรูปบน Android 14 ขึ้นไป ให้แสดงแถบ "เลือกรูปเพิ่ม" และ "อนุญาตทั้งหมด"
- กดค้างที่ภาพเพื่อดูตัวอย่างแบบ glass ปล่อยนิ้วแล้วปิด มีอยู่แล้ว ให้คงไว้
- หน้าดูภาพ: แชร์, สลับต้นฉบับกับภาพ AI, ข้อมูลภาพ, ปุ่มไปหน้ารวม ปัดซ้ายขวาเพื่อดูภาพถัดไปถ้าทำได้

## เงื่อนไข

- คงตรรกะเดิมของ Luma shot ไว้ทั้งหมด ได้แก่ AI/RAW/DNG, ลองใหม่, `EnhanceWorker`, ข้อมูลภาพ
- ปุ่มต้องมีขนาดอย่างน้อย 48 dp, มี contentDescription และข้อความไม่ถูกตัดที่ font 2.0
- เคารพ `Glass.reduced()` คือไม่มีแอนิเมชันเมื่อเปิดลดการเคลื่อนไหว
- อ่าน MediaStore นอก main thread และจำกัด bitmap ให้เล็กพอสำหรับ grid
- `StudioAccessibilityTest` ตรวจหน้า Gallery อยู่แล้ว ต้องไม่เพิ่ม finding
